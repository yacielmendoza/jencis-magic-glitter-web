# Jencis Magic Glitter — Sitio web

Landing page estática (HTML/CSS/JS, sin build) de **Jencis Magic Glitter** — vasos snow globe personalizados, Big Spring, TX.

## Estructura
- `index.html` — la página (bilingüe ES/EN, catálogo, FAQ, formulario de pedidos por WhatsApp).
- `assets/` — logo e ícono.
- `netlify.toml` — config de despliegue para Netlify.

## Editar
Todo el contenido está en `index.html`. Para cambiar el número de WhatsApp o los @usuarios, edita el bloque `const CONFIG` al inicio del `<body>`.

## Desplegar
Ver `DEPLOY.md`. Resumen: conectar este repo de GitHub a Netlify o Vercel → despliegue automático en cada `git push`.
